# Stylish Fonts

Transform your plain text into eye-catching stylish fonts directly from your keyboard. Perfect for social media, messaging, and creative expression.

<Accordion>
<AccordionItem title="Access Stylish Fonts">
1. Open any app where you can type (Messages, WhatsApp, Instagram, etc.)
2. Tap on a text field to bring up the Flashboard keyboard
3. Tap the **Aa font icon** in the top toolbar
4. Browse through available font styles
</AccordionItem>

<AccordionItem title="How to Use Stylish Fonts">
### Method 1: Type First, Style Later
1. Type your message normally on the keyboard
2. Tap the **Aa font icon** in the top toolbar
3. Select your preferred font style
4. Your text automatically converts to the selected style
5. Tap **Apply** or continue typing

### Method 2: Select Style First
1. Tap the **Aa font icon** before typing
2. Choose a font style
3. Start typing - text appears in the selected style
4. Tap the **Aa icon** again to switch styles or return to normal

### Method 3: Convert Existing Text
1. Type or paste text into the Flashboard text editor
2. Open the **Aa font menu**
3. Scroll through previews - each shows how your text will look
4. Tap the style you want
5. Copy or share the converted text
</AccordionItem>

<AccordionItem title="Font Style Categories">
Access different categories by swiping the font picker:

1. **Popular** - Most-used stylish fonts
2. **All Fonts** - Complete font collection
3. **Favorites** - Your saved favorite styles
</AccordionItem>

<AccordionItem title="Save Favorite Fonts">
1. Open the **Aa font menu**
2. Long-press any font style
3. Tap **Add to Favorites** ⭐
4. Access favorites from the **Favorites tab**

To remove from favorites:
1. Go to **Favorites tab**
2. Long-press the font style
3. Tap **Remove from Favorites**
</AccordionItem>

<AccordionItem title="Tips for Using Stylish Fonts">
**Social Media Posts**
- Use bold serif or script fonts for captions
- Combine regular and stylish text for emphasis
- Works great on Instagram, Facebook, Twitter/X

**Direct Messages**
- Add personality to WhatsApp and Telegram messages
- Use sparingly for impact
- Great for greetings and signatures

**Usernames & Bios**
- Create unique profile names with decorative fonts
- Stand out in comments and replies
- Some platforms may have font restrictions

**Accessibility Note**
- Stylish fonts may not be readable by screen readers
- Use regular text for important information
- Consider your audience
</AccordionItem>

<AccordionItem title="Troubleshooting">
### Font not showing in other apps?
- The receiving device or app may not support Unicode decorative fonts
- Try a different font style
- Test with a simpler style like Bold Serif

### Text appears as boxes or question marks?
- The device lacks font support for those Unicode characters
- Use more widely-supported styles
- Update the receiving device's operating system

### Can't find the font icon?
- Look for **Aa** in the top toolbar of Flashboard
- Ensure you have the latest Flashboard version
- Check if custom toolbar is enabled in Settings

### Want to disable stylish fonts?
- You can hide the font icon from **Settings** > **Toolbar** > **Customize**
</AccordionItem>
