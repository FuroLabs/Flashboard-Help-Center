# Customizing Themes

Make Flashboard truly yours with custom themes, colors, and visual styles. Choose from dozens of built-in themes or create your own.

<Accordion>
<AccordionItem title="Apply Built-in Themes">
1. Open the **Flashboard app**
2. Go to **Settings** > **Themes**
3. Browse the **Theme Gallery**
4. Tap a theme to preview
5. Tap **Apply** to set as your active theme

### Theme Categories

**Light Themes**
- **Clean White** - Minimalist white background
- **Soft Pearl** - Off-white with subtle shadows
- **Daylight** - Bright and clear for sunny environments

**Dark Themes**
- **Classic Dark** - High contrast, professional black
- **Midnight Blue** - Deep blue tones, easy on eyes
- **Carbon** - Sleek dark gray with modern feel
- **AMOLED Black** - Pure black for battery saving

**Colorful Themes**
- **Ocean** - Blue gradient with aqua accents
- **Sunset** - Orange and pink gradient
- **Forest** - Green nature-inspired palette
- **Purple Dream** - Vibrant purple and violet

**Special Themes**
- **Gradient Flow** - Dynamic color transitions
- **Neon Nights** - Bright neon colors on dark background
- **Rose Gold** - Elegant pink-gold metallic
- **Material You** - Adapts to Android 12+ system colors
</AccordionItem>

<AccordionItem title="Quick Theme Switching">
Switch themes without opening the app:

1. Open any text field to bring up Flashboard
2. **Long-press the settings icon** ⚙️ in the toolbar
3. Tap **Themes**
4. Select from recently used themes
5. Theme changes instantly
</AccordionItem>

<AccordionItem title="Create Custom Themes">
### Use Theme Builder

1. Open **Flashboard app** > **Settings** > **Themes**
2. Tap **+ Create Custom Theme**
3. Choose a base theme to start from
4. Customize colors:
   - **Key background** - Color of letter keys
   - **Key text** - Letter and symbol colors
   - **Keyboard background** - Overall keyboard color
   - **Accent color** - Highlighting and active elements
   - **Special keys** - Enter, Space, Backspace colors
   - **Border** - Key outline colors (optional)

5. Preview in real-time
6. Tap **Save** and name your theme
7. Tap **Apply** to use immediately

### Advanced Theme Customization

Access more granular controls:

1. In **Theme Builder**, tap **Advanced Options**
2. Customize additional elements:
   - **Key press feedback color**
   - **Gesture trail color**
   - **Suggestion bar background**
   - **Popup preview colors**
   - **Shadow and elevation**
   - **Corner radius** (rounded vs square keys)
   - **Key spacing and padding**

### Use Image Backgrounds

Set a photo or image as your keyboard background:

1. Go to **Settings** > **Themes** > **Custom Theme**
2. Tap **Background** > **Image**
3. Choose source:
   - **Gallery** - Pick from your photos
   - **Camera** - Take a new photo
   - **Stock Images** - Use Flashboard's collection
4. Adjust image:
   - **Position** - Center, fit, fill, or stretch
   - **Opacity** - Make image more/less visible
   - **Blur** - Add blur for text readability
5. Tap **Apply**

**Background Tips:**
- Use low-contrast images for better key visibility
- Apply blur (30-50%) for text readability
- Reduce opacity (50-70%) if keys are hard to see
- Test typing in different lighting conditions

### Gradient Themes

Create smooth color transitions:

1. In **Theme Builder**, select **Gradient Background**
2. Choose gradient type:
   - **Linear** - Straight gradient direction
   - **Radial** - Circular gradient from center
   - **Angular** - Rotating gradient
3. Add color stops (2-5 colors)
4. Adjust angle and position
5. Preview and save
</AccordionItem>

<AccordionItem title="Import & Share Themes">
### Download Community Themes

1. Open **Flashboard app** > **Themes** > **Community**
2. Browse themes created by others
3. Tap a theme to preview
4. Tap **Download** to add to your collection
5. Tap **Apply** to use

### Share Your Custom Theme

1. Go to **Settings** > **Themes** > **My Themes**
2. Select a custom theme you created
3. Tap **Share**
4. Choose sharing method:
   - **Theme Code** - Copy code to share via text
   - **QR Code** - Others scan to import
   - **Community** - Upload to theme gallery (requires account)

### Import Theme from Code

1. Copy a theme code shared by someone
2. Open **Flashboard app** > **Themes**
3. Tap **+ Import Theme**
4. Paste the theme code
5. Preview and apply
</AccordionItem>

<AccordionItem title="Theme Settings">
### Auto-Switch Themes

Automatically change themes based on time or app:

**Time-Based:**
1. Go to **Settings** > **Themes** > **Auto-Switch**
2. Enable **Time-Based Switching**
3. Set:
   - **Day Theme** - Active from 6 AM to 6 PM
   - **Night Theme** - Active from 6 PM to 6 AM
4. Adjust times as needed

**App-Based:**
1. Enable **Per-App Themes**
2. Tap **Add App Rule**
3. Select an app
4. Choose theme for that app
5. Theme changes automatically when you type in that app

**System-Based:**
1. Enable **Follow System Theme**
2. Keyboard switches between light/dark based on Android system setting

### Theme Backup & Restore

**Backup Themes:**
1. Go to **Settings** > **Themes** > **Backup**
2. Tap **Backup All Themes**
3. Save to:
   - Google Drive
   - Local storage
   - Export as file

**Restore Themes:**
1. Go to **Themes** > **Restore**
2. Select backup file
3. Choose which themes to restore
4. Tap **Restore**
</AccordionItem>

<AccordionItem title="Optimize Theme Performance">
### Battery-Friendly Themes

For longer battery life:
1. Use **AMOLED Black** theme on OLED screens
2. Disable dynamic effects and animations
3. Reduce transparency and blur effects
4. Use solid colors instead of gradients

### Performance Settings

1. Go to **Settings** > **Themes** > **Performance**
2. Toggle:
   - **Reduce animations** - Faster, uses less battery
   - **Disable transparency** - Improves performance
   - **Static background** - No gradients or effects
   - **Simple shadows** - Lighter rendering
</AccordionItem>

<AccordionItem title="Theme Accessibility">
### High Contrast Themes

For better visibility:
1. Go to **Themes** > **Accessibility Themes**
2. Choose:
   - **High Contrast Dark** - White text on black
   - **High Contrast Light** - Black text on bright white
   - **Yellow on Black** - Maximum contrast
3. Adjust **Key Border Width** for clearer key separation

### Large Keys Mode

Combined with themes for easier viewing:
1. **Settings** > **Keyboard** > **Key Height**
2. Increase to **Large** or **Extra Large**
3. Pair with high contrast theme
</AccordionItem>

<AccordionItem title="Troubleshooting Themes">
### Theme not applying?
- Restart the Flashboard app
- Check if theme is fully downloaded
- Clear app cache: **Settings** > **Advanced** > **Clear Cache**
- Redownload the theme

### Keys hard to see?
- Increase **Key Border Width** in theme settings
- Use a high contrast theme
- Reduce background image opacity
- Enable **Key Press Highlight**

### Theme looks different on keyboard?
- Some apps override keyboard colors
- Check if app uses dark/light mode
- Disable per-app theming if conflicts occur

### Custom theme not saving?
- Check storage permissions
- Free up device storage space
- Try creating a simpler theme first
- Update Flashboard to latest version
</AccordionItem>
