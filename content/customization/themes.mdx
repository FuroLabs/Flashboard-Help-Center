# Customizing Themes

Make Flashboard your own with our powerful theming engine.

## Built-in Themes
Flashboard comes with 3 gorgeous presets:
- **Default Dark**: High contrast, professional look.
- **Solarized Light**: Easy on the eyes for daytime work.
- **Midnight Blue**: Deep, calming blue tones.

## creating a Custom Theme
You can create your own theme by editing the `theme.json` file in your configuration folder.

```json
{
  "name": "My Theme",
  "colors": {
    "background": "#1a1a1a",
    "primary": "#ff0000"
  }
}
```
