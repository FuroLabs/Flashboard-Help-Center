# Frequently Asked Questions

Quick answers to the most common questions about Flashboard.

<Accordion>
<AccordionItem title="General Questions">
### Is Flashboard free?

Yes, Flashboard offers a free version with all core keyboard features including:
- Full keyboard functionality
- Multiple themes
- Gesture controls
- Basic clipboard history
- Sinhala language support

**Pro features** (optional subscription):
- Unlimited clipboard history
- Advanced themes and customization
- No ads
- Premium fonts and Flash Arts
- Priority support

### What languages does Flashboard support?

**Currently supported:**
- English (US, UK, Australia, Canada)
- Sinhala (සිංහල) with phonetic and Unicode converter
- Tamil (தமிழ்)
- Hindi (हिन्दी)
- Spanish (Español)
- French (Français)

More languages coming soon! Check **Settings** > **Languages** for the latest list.

### Does Flashboard work offline?

Yes! Flashboard works completely offline:
- No internet required for typing
- All features available offline
- Learning and predictions work locally
- Internet only needed for: app updates, theme downloads, and cloud backup (optional)

### What Android version do I need?

**Minimum:** Android 8.0 (Oreo, API 26)
**Recommended:** Android 10 or higher for best performance and all features

### Is Flashboard safe to use?

Absolutely. Flashboard prioritizes your privacy:
- ✅ We never log your keystrokes
- ✅ All data stored locally on your device
- ✅ No access to other apps' data
- ✅ Compliant with Google Play security standards
- ✅ Regular security audits

See [Data Safety & Privacy](/privacy/data-safety) for details.
</AccordionItem>

<AccordionItem title="Installation & Setup">
### How do I install Flashboard?

1. Download from **Google Play Store**
2. Open the app and follow setup wizard
3. Enable Flashboard in Android Settings
4. Set as default keyboard

See the complete [Installation Guide](/setup/installation).

### Flashboard isn't appearing in my keyboard list?

**Try these steps:**
1. Go to **Android Settings** > **Apps** > **Flashboard**
2. Ensure permissions are granted
3. Force stop and restart the app
4. Restart your device
5. Reinstall Flashboard if problem persists

### How do I switch to Flashboard while typing?

**Quick method:**
1. **Long-press the spacebar** while typing
2. Select **Flashboard** from the keyboard picker

Or tap the **keyboard icon** in your navigation bar.

### Can I use multiple keyboards?

Yes! You can switch between Flashboard and other keyboards anytime:
- Long-press spacebar to choose
- Keep your default keyboard as backup
- Different keyboards for different apps
</AccordionItem>

<AccordionItem title="Features & Functionality">
### How does swipe typing work?

1. Place finger on first letter
2. Slide through each letter without lifting
3. Lift finger after last letter
4. Word appears automatically with space

See [Gesture Controls](/features/gestures) for more.

### How do I access emojis and Flash Arts?

**Emojis:**
- Tap the **😊 emoji button** (usually next to spacebar)

**Flash Arts:**
- Tap emoji button
- Swipe to the **middle tab**
- Browse ASCII art, emoticons, and decorative text

See [Flash Arts](/creative-tools/flash-arts) guide.

### Can I type in Sinhala?

Yes! Flashboard has excellent Sinhala support:
- Phonetic typing
- Unicode converter for FM fonts
- Full Sinhala character support

See [Sinhala Phonetics Typing](/setup/sinhala-phonetics) and [Unicode Converter](/features/unicode-converter).

### How do I use clipboard history?

1. Tap the **📋 clipboard icon** in toolbar
2. Browse your copy history
3. Tap any clip to paste
4. Long-press to delete or pin clips

See [Clipboard Manager](/features/clipboard).

### What are keyboard signatures?

Signatures are custom text you can paste instantly:
- Email signatures
- Social media handles
- Common phrases
- Contact information

Tap the **✍️ signature icon** to paste. See [Keyboard Signature](/features/keyboard-signature).
</AccordionItem>

<AccordionItem title="Customization">
### How do I change keyboard themes?

1. Open **Flashboard app** > **Settings** > **Themes**
2. Browse theme gallery
3. Tap a theme to preview
4. Tap **Apply**

See [Customizing Themes](/customization/themes).

### Can I use my own photo as keyboard background?

Yes!
1. **Settings** > **Themes** > **Create Custom**
2. Tap **Background** > **Image**
3. Choose from gallery or take photo
4. Adjust opacity and blur
5. Apply

### How do I make keys bigger?

1. **Settings** > **Keyboard** > **Key Height**
2. Choose: Small, Medium, **Large**, or Extra Large
3. Adjust keyboard height by dragging the top edge

### Can I change key sounds?

1. **Settings** > **Sound & Vibration**
2. Toggle **Key Press Sound**
3. Choose sound style: Click, Pop, Typewriter, Silent
4. Adjust volume
</AccordionItem>

<AccordionItem title="Troubleshooting">
### Keyboard is laggy or slow?

**Quick fixes:**
1. Clear cache: **Settings** > **Advanced** > **Clear Cache**
2. Reduce theme complexity (disable animations)
3. Disable unused features
4. Restart device
5. Free up device storage

### Autocorrect is too aggressive?

1. **Settings** > **Text Correction**
2. Adjust **Auto-Correction Level**: Off, Mild, Moderate, Aggressive
3. Disable specific corrections
4. Add words to dictionary

### Wrong predictions appearing?

**Reset learning:**
1. **Settings** > **Advanced** > **Clear Learned Words**
2. This resets personalized suggestions
3. Keyboard will learn again as you type

### Swipe typing not working?

1. Enable in **Settings** > **Gestures** > **Swipe Typing**
2. Check if language supports swipe input
3. Update Flashboard to latest version
4. Try tapping instead of swiping

### Keyboard randomly crashes?

1. Update to latest version from Play Store
2. Clear app cache and data
3. Check for Android system updates
4. Enable crash reporting: **Settings** > **Privacy** > **Crash Reports**
5. Contact support with crash details
</AccordionItem>

<AccordionItem title="Privacy & Security">
### Can you see what I type?

**No.** Flashboard never logs, records, or transmits your keystrokes. Everything stays on your device.

### What permissions does Flashboard need?

**Required:**
- Input method permission (to function as keyboard)

**Optional:**
- Microphone (for voice typing)
- Storage (for custom themes and backups)
- Contacts (for name suggestions)

All optional permissions can be denied without affecting core functionality.

### Does Flashboard send data to servers?

Only with your permission:
- Anonymous usage statistics (optional)
- Crash reports (optional)
- Theme downloads (only when you request)
- App updates

Your typed content is never sent anywhere.

### How do I delete all my data?

**Delete local data:**
1. **Settings** > **Privacy** > **Delete All Data**
2. Or **Android Settings** > **Apps** > **Flashboard** > **Storage** > **Clear Data**

**Uninstall completely:**
1. Long-press Flashboard app icon
2. Tap **Uninstall**
3. All local data is deleted
</AccordionItem>

<AccordionItem title="Technical Issues">
### Keyboard not showing up in some apps?

Some apps have custom input methods or security restrictions:
- Banking apps may block third-party keyboards
- Password fields often default to system keyboard
- Secure apps may require Google Keyboard

This is normal Android behavior for security.

### Keyboard opens but keys don't type?

1. Check if keyboard permission is granted
2. Force stop Flashboard app and restart
3. Clear app cache
4. Restart device
5. Reinstall if problem persists

### Theme not applying properly?

1. Restart Flashboard app
2. Re-apply the theme
3. Clear cache
4. Check if theme file is fully downloaded
5. Try a different theme to isolate issue

### Voice typing not working?

1. Grant microphone permission
2. Check if Google Voice Typing is installed
3. Test microphone in another app
4. Enable voice input: **Settings** > **Voice Input**
5. Check Android system voice settings
</AccordionItem>
