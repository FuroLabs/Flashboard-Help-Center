# In-Keyboard Calculator

Solve math problems instantly without leaving your keyboard or switching apps. Flashboard's built-in calculator lets you type equations and get results on the fly—perfect for quick calculations while messaging, browsing, or working in any app.

## Why Use In-Keyboard Calculator

Tired of switching between apps for simple math? Whether you need to calculate a tip, split a bill, or solve a quick equation, the in-keyboard calculator keeps you productive without interruption.

**Key Benefits:**
- Calculate instantly without leaving your current app
- Support for basic and advanced math operations
- Customizable display options for results
- No app switching needed

<AccordionItem title="How to Use">

### Type an Expression

1. Open any app where you can type
2. Bring up the Flashboard keyboard
3. Type your math expression (e.g., `2+2`, `(10*5)/2`, `15.5-3.2`)
4. Press the **= (equals) key** to calculate
5. The result appears instantly in your text field

### Examples

Here are some expressions you can try:

- **Simple addition:** `2+2=` → `4`
- **With parentheses:** `(10*5)/2=` → `25`
- **Decimals:** `19.99/2=` → `9.995`
- **Multiple operations:** `100+50-25*2=` → `100`
- **Complex expressions:** `((15+5)*2)/4=` → `10`

### Tips for Best Results

1. Type the complete expression before pressing equals
2. Use clear spacing if needed (spaces are optional)
3. Press **= or Enter** to trigger the calculation
4. The original calculation can be kept or replaced based on your settings

<AccordionItem title="Supported Operations">

### Basic Operations

The calculator supports all fundamental math operations:

- **Addition:** `+` (e.g., `5+3`)
- **Subtraction:** `-` (e.g., `10-4`)
- **Multiplication:** `*` (e.g., `6*7`)
- **Division:** `/` (e.g., `20/4`)

### Advanced Features

For more complex calculations, use these features:

- **Parentheses:** `( )` - Control order of operations (e.g., `(5+3)*2`)
- **Decimal Numbers:** Use `.` for decimal values (e.g., `3.14*2`)
- **Negative Numbers:** Use `-` for negative values (e.g., `-5+10`)
- **Multiple Operations:** Combine operators in one expression (e.g., `100+50-25`)

### Order of Operations

The calculator follows standard mathematical rules (PEMDAS):

1. **Parentheses** first
2. **Multiplication & Division** (left to right)
3. **Addition & Subtraction** (left to right)

**Example:** `2+3*4=` gives `14` (not `20`), because multiplication happens before addition.

<AccordionItem title="Settings">

### Enable or Disable Calculator

1. Open **Flashboard Settings**
2. Go to **Keyboard Features** or **Tools**
3. Toggle **In-Keyboard Calculator** on/off
4. Changes apply immediately

### Keep Original Expression

Choose how results are displayed:

**Keep Expression On (Default)**
- Shows: `2+2=4`
- The original equation and result stay visible
- Useful for verification and learning

**Keep Expression Off**
- Shows: `4`
- Only the result is inserted
- Cleaner output for quick calculations

**To Change This Setting:**
1. Open **Flashboard Settings**
2. Navigate to **Calculator Settings**
3. Toggle **Keep Original Expression**
4. Save your preference

### Precision Settings

Control how many decimal places are shown:

1. Open **Flashboard Settings**
2. Go to **Calculator Settings**
3. Select **Decimal Precision**
4. Choose your preference:
   - **0 decimals:** `10/3=` → `3`
   - **2 decimals:** `10/3=` → `3.33`
   - **4 decimals:** `10/3=` → `3.3333`

**Rounding Rules:**
- Standard mathematical rounding is applied
- Unnecessary trailing zeros are removed

<AccordionItem title="Troubleshooting">

### Calculator Isn't Triggering

**Problem:** Nothing happens when I press equals after typing an equation.

**Solutions:**
1. Make sure the calculator is **enabled** in Settings → Keyboard Features
2. Verify you used a **valid expression** (e.g., not just `=` or `2++3`)
3. Try pressing **= or Enter** after the expression
4. Check that your keyboard focus is in a text field

### Getting Wrong Results

**Problem:** The calculator is giving unexpected results.

**Solutions:**
1. **Check parentheses:** Ensure all opening `(` brackets have closing `)` brackets
2. **Review operation order:** Remember PEMDAS - multiplication/division before addition/subtraction
3. **Verify decimal usage:** Ensure decimals are written correctly (e.g., `3.5`, not `3,5`)
4. **Clear the expression:** Start fresh if confused - type a new expression

### Expression Not Recognized

**Problem:** I typed a valid expression but it won't calculate.

**Solutions:**
1. Make sure there are **no spaces between operators** if your keyboard adds them (e.g., use `2+2` not `2 + 2`)
2. Avoid starting with operators (e.g., `+5` won't work, but `0+5` will)
3. **Don't use `×` or `÷` symbols** - use `*` and `/` instead
4. Ensure you're in a **text input field** where the keyboard is active

### Decimal Precision Issues

**Problem:** Results show too many or too few decimal places.

**Solution:**
1. Adjust the **Decimal Precision** setting in Calculator Settings
2. Choose the number of decimal places that suits your needs
3. Results will round automatically according to your selection

### Need Help?

If issues persist:
- Restart the Flashboard keyboard
- Reopen the app you're typing in
- Update Flashboard to the latest version
- Contact Flashboard support with details of your calculation
