# Keyboard Signature

Create custom text signatures and paste them instantly with a single tap. Perfect for email sign-offs, social media bios, contact information, or any frequently used text.

## What is a Keyboard Signature?

A keyboard signature is a custom text string you create once and paste anytime from the Flashboard toolbar. Think of it as your personal quick-paste button.

**Common Uses:**
- Email signatures with name and contact info
- Social media handles and hashtags
- Standard replies and greetings
- Addresses and phone numbers
- Custom emojis and text art
- Professional disclaimers

<Accordion>
<AccordionItem title="Create Your First Signature">

1. Open the **Flashboard app**
2. Go to **Settings** > **Keyboard Signature**
3. Tap **+ Create Signature**
4. Enter your signature text
5. Optionally add a **Signature Name** (for reference)
6. Tap **Save**

### Example Signatures

**Professional Email:**
```
Best regards,
John Doe
Marketing Manager
john@company.com
+1 (555) 123-4567
```

**Social Media:**
```
Follow me @johndoe
📸 Daily updates | 🎨 Creative content
#YourHashtag
```

**Quick Reply:**
```
Thanks for your message!
I'll get back to you soon. 😊
```

</AccordionItem>

<AccordionItem title="Paste Your Signature">

### Using the Top-Bar Icon

1. Open any app where you can type
2. Bring up the Flashboard keyboard
3. Tap the **✍️ signature icon** in the top toolbar
4. Your signature is instantly pasted

### Using Multiple Signatures

If you have multiple signatures:

1. Tap the **✍️ signature icon**
2. A menu appears showing all your signatures
3. Tap the signature you want to paste

</AccordionItem>

<AccordionItem title="Manage Signatures">

### Edit a Signature

1. Open **Flashboard app** > **Settings** > **Keyboard Signature**
2. Tap the signature you want to edit
3. Make your changes
4. Tap **Save**

### Reorder Signatures

1. Open **Keyboard Signature** settings
2. Long-press the **⋮⋮** handle next to a signature
3. Drag to reorder
4. Signatures appear in this order in the paste menu

### Delete a Signature

1. Open **Keyboard Signature** settings
2. Swipe left on the signature you want to remove
3. Tap **Delete**
4. Confirm deletion

Or:
1. Tap the signature to edit
2. Scroll to bottom
3. Tap **Delete Signature**

</AccordionItem>

<AccordionItem title="Advanced Signature Features">

### Use Placeholders

Add dynamic content to signatures:

**Available Placeholders:**
- `{date}` - Current date
- `{time}` - Current time
- `{day}` - Day of week
- `{month}` - Current month
- `{year}` - Current year

**Example:**
```
Meeting scheduled for {date} at {time}
See you on {day}!
```

When pasted, becomes:
```
Meeting scheduled for Feb 8, 2025 at 2:30 PM
See you on Saturday!
```

### Add Formatted Text

Signatures support:
- ✅ Line breaks and spacing
- ✅ Emojis and special characters
- ✅ Stylish fonts (created with [Stylish Fonts](/customization/stylish-fonts))
- ✅ Unicode characters
- ✅ Links (will be clickable when pasted)

### Signature Shortcuts

Create keyboard shortcuts for quick access:

1. Edit a signature in settings
2. Enable **Assign Shortcut**
3. Set a shortcut text (e.g., "/sig", "::email")
4. Tap **Save**

Now when you type the shortcut, the full signature appears as a suggestion above the keyboard.

</AccordionItem>

<AccordionItem title="Signature Settings">

Customize signature behavior:

1. Open **Flashboard app** > **Settings** > **Keyboard Signature**
2. Tap **⚙️ Signature Settings**

**Show Signature Icon**
- Toggle visibility of the ✍️ icon in the toolbar

**Quick Paste**
- Enable to paste immediately (single signature)
- Disable to show menu (multiple signatures)

**Append Line Break**
- Automatically add a line break after pasting signature

**Show in Suggestions**
- Display signatures as suggestions while typing

**Signature Position**
- Choose where signature pastes: at cursor or end of text

</AccordionItem>

<AccordionItem title="Tips for Great Signatures">

1. **Keep it concise** - Shorter signatures are more practical
2. **Use multiple signatures** - Different contexts need different signatures
3. **Include key info** - Name, contact method, or social handle
4. **Test readability** - Make sure emojis and fonts display correctly
5. **Update regularly** - Keep contact info current

<AccordionItem title="Troubleshooting">

### Signature icon not visible?
- Go to **Settings** > **Toolbar** > enable **Signature Icon**
- Check if you have at least one signature created
- Restart Flashboard keyboard

### Signature not pasting correctly?
- Check if the target app supports multi-line text
- Some apps may strip formatting
- Try a simpler signature without special characters

### Placeholders not working?
- Ensure you're using the correct syntax: `{date}` not `{Date}`
- Update Flashboard to the latest version
- Some placeholders may not be available in older versions

### Shortcut not triggering signature?
- Make sure **Show in Suggestions** is enabled
- Check that shortcut text doesn't conflict with real words
- Try typing the shortcut and waiting a moment for suggestions
