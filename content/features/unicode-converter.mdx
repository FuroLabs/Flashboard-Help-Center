# Unicode Converter (FM Sinhala Fonts)

Flashboard includes a powerful Unicode converter that lets you type in FM Sinhala font format and convert between legacy FM fonts and modern Unicode Sinhala.

<Accordion>
<AccordionItem title="What is Unicode Conversion?">
**FM fonts** are legacy Sinhala fonts that use custom character encoding. **Unicode** is the modern standard that ensures text displays correctly everywhere.

The Unicode Converter helps you:
- Type in FM font format (for legacy systems)
- Convert FM font text to Unicode Sinhala
- Convert Unicode Sinhala to FM fonts
- Ensure compatibility across different platforms
</AccordionItem>

<AccordionItem title="Enable Unicode Converter">
1. Open the **Flashboard app**
2. Go to **Settings** > **Languages & Input**
3. Find **Sinhala Settings**
4. Toggle **Enable FM Font Unicode Converter** to ON
5. Select your preferred **FM font encoding** (FM Abhaya, FM Malithi, etc.)
</AccordionItem>

<AccordionItem title="Use the Top-Bar Converter Icon">
Once enabled, you'll see a **🔄 converter icon** in the Flashboard top toolbar.

### Convert Text While Typing

1. Type your Sinhala text using the keyboard
2. Tap the **🔄 converter icon** in the top toolbar
3. Select conversion direction:
   - **Unicode → FM Font** - Convert to legacy FM encoding
   - **FM Font → Unicode** - Convert to modern Unicode
4. Your text is instantly converted

### Convert Copied Text

1. Copy text from any app (long-press text > Copy)
2. Open Flashboard in any text field
3. Tap the **🔄 converter icon**
4. Tap **Paste & Convert**
5. Select conversion direction
6. Converted text appears in the text field
</AccordionItem>

<AccordionItem title="Type Directly in FM Font Format">
### Enable FM Font Input Mode

1. While typing, tap the **🔄 converter icon**
2. Toggle **FM Font Mode** to ON
3. The icon changes color to indicate FM mode is active
4. Start typing in FM font format
5. Text appears as FM-encoded characters

### Switch Between Modes

- Tap the **🔄 icon** to toggle between Unicode and FM Font modes
- Current mode is indicated by the icon color:
  - **Blue icon** - Unicode mode (default)
  - **Orange icon** - FM Font mode active
</AccordionItem>

<AccordionItem title="Supported FM Font Encodings">
Flashboard supports multiple FM Sinhala font standards:

- **FM Abhaya** - Most widely used legacy font
- **FM Malithi** - Popular for formal documents
- **FM Bindumathi** - Traditional style
- **FM Samantha** - Modern looking FM font
- **FM Derana** - News and media standard

### Change FM Font Encoding

1. Open **Flashboard app** > **Settings** > **Languages**
2. Tap **Sinhala Settings**
3. Select **FM Font Encoding**
4. Choose your preferred encoding
5. Tap **Apply**
</AccordionItem>

<AccordionItem title="Batch Convert Documents">
Convert larger amounts of text:

1. Open the **Flashboard app** (not just the keyboard)
2. Go to **Tools** > **Unicode Converter**
3. Tap **Import Text**
4. Paste or type your content
5. Select **Conversion Direction**
6. Tap **Convert**
7. Copy the result or share it directly
</AccordionItem>

<AccordionItem title="Unicode Converter Settings">
Customize converter behavior:

1. Open **Flashboard app** > **Settings** > **Languages** > **Sinhala**
2. Find **Unicode Converter Settings**:

**Default Conversion Direction**
- Choose what happens when you tap the converter icon

**Show Converter in Toolbar**
- Toggle visibility of the 🔄 icon

**Auto-Detect Encoding**
- Let Flashboard detect whether text is Unicode or FM Font

**Preserve Formatting**
- Keep line breaks and spacing during conversion
</AccordionItem>

<AccordionItem title="Why Use Unicode Instead of FM Fonts?">
**Unicode Advantages:**
- ✅ Displays correctly on all devices and platforms
- ✅ Supported by Google, Facebook, WhatsApp, all modern apps
- ✅ No special fonts needed
- ✅ Better for search and text processing
- ✅ Future-proof standard

**When to Use FM Fonts:**
- 📄 Legacy documents and systems
- 🖨️ Old printing presses
- 📰 Traditional newspaper systems
- 💻 Compatibility with old software

**Recommendation:** Always use Unicode for new content. Only convert to FM fonts when required by legacy systems.
</AccordionItem>

<AccordionItem title="Troubleshooting">
### Converter icon not appearing?
- Go to **Settings** > **Toolbar** > ensure **Unicode Converter** is enabled
- Make sure Sinhala language is enabled
- Restart the Flashboard app

### Conversion produces incorrect characters?
- Check you've selected the correct FM font encoding
- Try **Auto-Detect Encoding** in settings
- Verify the source text uses a supported FM font
- Update Flashboard to the latest version

### Text looks jumbled after conversion?
- Ensure the receiving app supports Unicode Sinhala
- Update the app you're pasting into
- Try converting in the opposite direction
- Some very old FM fonts may not be fully supported

### FM Font Mode won't activate?
- Confirm **Enable FM Font Unicode Converter** is ON in settings
- Check that you've selected an FM font encoding
- Restart Flashboard keyboard
</AccordionItem>
