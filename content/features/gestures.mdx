# Gesture Controls

Swipe, pinch, and tap your way to speed.

## Common Gestures
| Action | Gesture | Result |
| :--- | :--- | :--- |
| **Delete Word** | Swipe Left (Two Fingers) | Deletes the previous word |
| **Cursor Move** | Slide on Spacebar | Moves cursor precisely |
| **Emoji Panel** | Long Press Enter | Opens Emoji picker |

## Customizing Gestures
Go to **Settings > Gestures** to remap these actions.
