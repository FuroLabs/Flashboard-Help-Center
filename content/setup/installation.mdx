# Installation Guide

Welcome to Flashboard! Follow these steps to get started.

## System Requirements
- OS: Windows 10/11, macOS 12+, or Linux
- RAM: 4GB minimum
- Disk Space: 500MB

## Installation Steps
1. Download the installer from our [Downloads Page](https://example.com).
2. Run the installer and follow the on-screen instructions.
3. Launch Flashboard from your desktop or start menu.

## Next Steps
Once installed, check out [Enabling Keyboard](/help/setup/enabling-keyboard) to configure your input settings.
