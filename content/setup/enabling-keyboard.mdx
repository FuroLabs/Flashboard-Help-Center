# Enabling Flashboard Keyboard

This guide covers activating Flashboard as your input method on Android.

<Accordion>
<AccordionItem title="Quick Enable (Fast Method)">
1. **Open any text field** (Messages, Email, Search bar, etc.)
2. **Long-press where you're typing** or tap the keyboard icon
3. **Select "Flashboard Keyboard"** from the keyboard options
4. **Start typing!**
</AccordionItem>

<AccordionItem title="Full Activation (Recommended)">
For the best experience, set Flashboard as your default keyboard:

**For Android 12 and Later**
1. Open **Settings**
2. Go to **System > Languages & Input**
3. Tap **On-screen keyboard**
4. Select **Flashboard Keyboard**
5. Tap **Set as default** (if prompted)

**For Android 11 and Earlier**
1. Open **Settings**
2. Tap **Languages & Input** or **Input Methods**
3. Select your current keyboard (usually "Default keyboard")
4. Choose **Flashboard Keyboard** from the list
5. Confirm the selection

**For Samsung Devices**
1. Open **Settings**
2. Go to **General > Languages and input**
3. Tap **On-screen keyboard** or **Keyboard list**
4. Select **Flashboard Keyboard**
5. Confirm activation
</AccordionItem>

<AccordionItem title="Grant Input Method Permission">
When you first enable Flashboard, you'll see a permission dialog:

> "Flashboard Keyboard wants to be your input method"

This is required for the keyboard to work. Tap **OK** or **Allow** to proceed.
</AccordionItem>

<AccordionItem title="Switch Between Keyboards">
- **Method 1**: Press and hold the **spacebar**, then select a different keyboard
- **Method 2**: Tap the **keyboard icon** in the navigation bar and select Flashboard
- **Method 3**: Use your device's keyboard switcher (notification or quick settings)
</AccordionItem>

<AccordionItem title="Verify Flashboard is Active">
Look for these indicators:
- ✅ **Flashboard logo** appears on the keyboard
- ✅ **App icon shows in developer notifications** (if developer mode is on)
- ✅ **Settings shows "Flashboard Keyboard"** as enabled input method
</AccordionItem>

<AccordionItem title="Troubleshooting">
**Flashboard doesn't appear in keyboard list**
- Go to **Settings > Apps** and ensure Flashboard has all permissions enabled
- Restart your device
- Reinstall Flashboard from the Play Store

**Can't find the keyboard setting**
- Different manufacturers use different menu structures
- Try searching "keyboard" in your Settings search bar
- Visit your manufacturer's support site for specific instructions

**Keyboard freezes or lags**
- See [Performance Troubleshooting](/help/troubleshooting/performance)
</AccordionItem>
