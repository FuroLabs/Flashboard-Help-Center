# Sinhala Phonetics Typing Key Help

Flashboard makes it easy to type in Sinhala using phonetic input. Type in English phonetic sounds and get Sinhala characters instantly.

<Accordion>
<AccordionItem title="Enable Sinhala Input">
1. Open the **Flashboard app**
2. Go to **Settings** > **Languages**
3. Tap **Add Language**
4. Select **Sinhala (සිංහල)**
5. Choose **Phonetic layout**
6. Tap **Done**
</AccordionItem>

<AccordionItem title="Switch to Sinhala Keyboard">
While typing in any app:

1. **Long-press the spacebar** or tap the **🌐 language icon**
2. Select **Sinhala** from the language list
3. Start typing phonetically
</AccordionItem>

<AccordionItem title="Example Words">
**Type "ayubowan"** → **ආයුබෝවන්**

**Type "sinhala"** → **සිංහල**

**Type "kohomadha"** → **කොහොමද**
</AccordionItem>

<AccordionItem title="Tips for Efficient Typing">
1. **Use capital letters** for long vowels: Type "kaama" or "kAma" for කාම
2. **Type phonetically**: Sound out words as you would speak them
3. **Use space to confirm**: Press space to finalize the current word
4. **Backspace works normally**: Delete characters one by one
</AccordionItem>

<AccordionItem title="Customize Sinhala Settings">
1. Open **Flashboard app** > **Settings** > **Languages**
2. Tap **Sinhala**
3. Adjust:
   - Auto-correction
   - Predictive text
   - Key long-press characters
</AccordionItem>

<AccordionItem title="Troubleshooting">
### Characters not appearing correctly?
- Ensure your device supports Sinhala Unicode fonts
- Update Android to the latest version
- Check if Sinhala language is enabled in Android Settings

### Wrong characters appearing?
- Check if you're using the phonetic layout (not inscript)
- Restart the Flashboard app
- Reset language settings and re-add Sinhala

### Need to type special characters?
- Long-press keys to access alternate characters
- Access the **symbols keyboard** via the **?123** key
</AccordionItem>
